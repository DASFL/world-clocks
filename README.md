# Мировые часы

Учебное приложение на React и TypeScript с классовыми компонентами.
Можно добавить город и его смещение UTC от −12 до +14, в том числе дробное.
Время отображается в формате ЧЧ:ММ:СС и обновляется каждую секунду.
Часы можно удалить — при этом их таймер останавливается.

Для запуска:

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале.
